# Prompt 变更记录

## 结论支持审核与受控改写复核v1（2026-10-24）

- 新增knowledge-support:v1：输入snapshotId及原问题、生成段落、引用原文；逐段输出SUPPORTED/UNSUPPORTED/UNKNOWN，严格覆盖编号与摘要。一次批量调用，最多1200输出Token/5秒，复用父任务剩余时限；不传生成器解释。同一配置模型独立调用，不能称独立模型证明。
- KnowledgeAnswerService在生成后、支持审核前重核权限/版本，审核后再次重核。任一段不通过整子问题EVIDENCE_ONLY；格式/阶段错误保留证据，不重试。无生成段落不调用审核。仅获准合成空间可外发，本轮无真实模型调用。
- 新增rewrite-review:v1：绑定原问题、改写及补检片段快照，判断meaning=PASS/BLOCK/UNKNOWN与逐项适用性ACCEPT/REJECT/UNKNOWN；ReviewedQueryExpansion接正式服务，默认rewrite-enabled=false，增强共享8秒，改写仍受自身5秒限制。审核失败保留原检索，完整资料及权限重新核对后才融合。
- 原生成、追问、学校分流和改写模板保持不变。本条覆盖此前“没有答案审核器/扩展未接线”的历史描述；7条已知漂移仍未真实复验，不能因替身通过宣布解决。后端2630项离线测试、前端92项、拦截页面42项及构建/打包通过，详见docs/知识库主线功能补齐与集中验证记录-2026-10-24.md。

## 学校范围与固定分段回答v1（2026-10-24，已接线、组织名单默认空）

- 新增knowledge-scope:v1：受控school范围、当前问题及可选可信话题，单次分类IN_SCOPE/OUT_OF_SCOPE/UNKNOWN；绑定snapshotId、连续原文逐字覆盖，禁止将资料不足等同校外。最多3分项、2000输出Token、阶段5秒，重用父任务剩余预算，不重试。
- 新增knowledge-scoped:v1：只回答questions中校内分项，一次批量生成，逐项原文与数量严格相等；证据编号/连续引文沿用原校验，最多3000输出Token。不调用额外答案审核器，结构通过不等于语义有据。

- PromptRegistry登记三个新节点；FollowUpResolver两轮共享5秒阶段、各最多500输出Token且不重试；KnowledgeAnswerComposer仅在获准关联时选择新回答节点，最多3000输出Token，所有调用复用原任务剩余预算。功能默认关闭，只有精确获准合成空间可发送历史原问题，真实企业资料不外发。
- 代码与离线验证：后端全量1592项通过，其中Resolver新增26项、模块18项、迁移1项、Composer1项共46项均包含在内；前端单元45项、企业拦截页面25项与构建通过。模型替身证明模板、字段、预算与降级契约，不证明真实追问准确率；新MySQL迁移与真实模型试验未执行，7条改写漂移未修复。
