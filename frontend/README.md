**已实现**：企业问答在工作台、知识空间、员工事务、公开联网体验之间切换时，保留当前账号最近十条问题、已收到的回答、未发送草稿及在途请求；返回页面不再次提交问题。退出、会话失效或更换账号时销毁旧问答缓存并取消客户端等待。刷新或关闭网页仍会丢失当前跨空间问答记录，本轮没有接入数据库历史恢复；取消客户端等待也不代表后端已终止模型执行。

### 企业工作台界面调整（2026-10-17）

- **工作台**：突出产品标语和企业知识主线；提供制度、业务、团队三个规划分类、功能接入状态及辅助事务入口。没有虚构文档数量、员工身份、通知或财务金额。
- **企业问答**：展示未来问题场景与接入边界。点击示例只给出说明，不发请求、不读取文件、不调用公开搜索或模型。
- **知识空间**：展示规划分类与空状态；文档、授权、入库服务接好前，不提供虚假的上传成功、检索结果或进度。
- **员工事务**：商品查询复用既有Mock接口；凭证补贴、参与确认和财务协同只展示规划和办理边界。
- **公开体验**：沿用原问答、分项结果、引用、并发、错误提示、导出和语言/时区设置；所有提问独立处理。持续提醒不要输入内部资料，企业示例不会转交此入口。

**为何这样选**：用独立工作台表达主辅业务，避免让通用聊天占据产品首页。沿用Vue与现有自定义样式，不新增路由、组件库或状态依赖；现阶段只有少量页面状态，后端服务并未同时扩建。

**代码与数据怎么走**：`src/App.vue` 第22—24行定义默认`home`及五个页面；`navigate()`（第176行）切换页面并收起导航和来源面板。`src/components/EnterpriseWorkspace.vue` 第5—18行定义页面参数、导航/商品事件与静态规划分类，第27—51行分支展示四个工作区。组件只向父组件发导航/弹窗事件，不发HTTP请求。`App.vue` 第283—285行保留原聊天实例；原问答仍由`api.ts`请求`POST /api/chat`，商品仍由`products.ts`请求`POST /api/products/search`。`index.html`同步产品标题与描述。

**问题与处理**：企业服务未接入时，示例只解释边界，不把内部制度问题误送公开搜索。切页通过`v-show`保留聊天状态及在途请求，`canSend`同时检查当前是否在公开体验页；切换回来不会新建或重发原请求。这是当前页面内保留，不等于刷新恢复。界面没有伪造登录身份，也没有把页面隐藏当作服务端鉴权。新企业区文案当前为中文，已有设置窗口和原问答词典继续工作，不能宣称全站完成六语种翻译。

**优化与代价**：后续真实企业身份与授权服务完成后，才替换知识空状态；有真实状态再显示负责人、版本与有效期。需要分享页面地址、浏览器后退和深链接时，再引入正式路由。需要细分权限时由后端返回可访问资源，不能单靠前端菜单。企业新页面的其他语种翻译另列待办。


真实提问通过 Vite 转发到 `http://127.0.0.1:8080/api/chat`，后端需要启用 `dev` 环境。此转发只用于开发；`npm run preview` 仅用于检查构建后的页面，不提供问答代理。生产部署及鉴权需另行完成。

无需在前端填写任何模型或搜索密钥。模型配置继续留在后端；联网检索还需要后端的 `TAVILY_API_KEY`。没有搜索凭据时，界面不会伪造搜索成功。

## 本单元做了什么

- 墨绿与暖白的问答工作台，包含导航、欢迎页、示例问题、输入框和来源面板。
- 当前页面内的新建会话、搜索、切换、移除、复制回答和文本导出。
- 对接现有 `Result<ChatAnswer>`：按子问题呈现完整回答、部分回答、资料不足和异常。
- 引用标记可定位来源；来源仅允许不带凭据的 HTTP/HTTPS 链接。回答以纯文本渲染，不执行模型返回的 HTML。
- 输入按 Unicode 字符计数，上限 500；支持中文输入法、Enter 发送及 Shift+Enter 换行。
- 单个请求不会锁住输入框，全页面最多同时等待两个请求，响应回填到对应问题。
- 95 秒前端等待上限，不自动重发；支持停止等待，并明确说明不能保证取消后台处理。
- 响应式侧栏、手机来源抽屉、键盘焦点、减少动画偏好以及页面内断网提示。

## 四方面记录

**为什么这样选**：Vue 响应式状态适合多个请求分别更新的聊天界面；TypeScript 对齐后端字段。自定义样式便于细化设计，因此暂不引入整套后台组件库，也不增加路由或全局状态管理依赖。

**代码和数据怎么走**：`src/App.vue` 管理页面内的 `Conversation → ChatTurn`。提交时立即插入等待项，`src/api.ts` 将 `{question, clientSubmittedAt, timeZone, answerLanguage}` 发给后端，校验外层错误码和内层回答契约，再更新原问题对应的条目。`AnswerText.vue` 只把已存在的来源编号转换为引用按钮；`AppIcon.vue` 使用固定的本地图标路径。`demo.ts` 只在点击“体验回答示例”时加载，醒目标注为演示，不发送任何外部请求。

**问题如何处理**：不能把 HTTP 200 当成回答完整，因此单独显示业务完成状态。网络错误、权限拒绝、接口不存在、服务不可用、业务失败、数据格式错误、超时均结束等待并给用户提示。不自动重试未知结果，避免重复费用。会话切换不丢弃在途请求；未完成的会话禁止移除。相互独立的请求不会串到其他问题下。

**后面如何优化**：界面稳定后可继续拆出会话列表、回答卡片和来源面板组件。后端具备鉴权、持久化任务和事件接口后，再增加会话恢复、真正的进度事件和历史上下文；当前不模拟这些能力。历史增多后再评估分页或虚拟列表。

## 当前边界

- 会话只存在当前页面内存中，刷新或关闭后清空；需要保留时请导出。
- 每条提问独立处理，当前不自动合并新旧问题，不向后端附加历史对话。
- 没有后台任务查询或断线恢复接口，刷新后不会自动重发或恢复原请求。
- 企业问答和知识空间已提供结构页，没有实现企业上传、解析、切分或权限向量检索。
- 页面不展示伪造的检索进度、置信度、令牌费用或执行轨迹。
- “界面演示”中的来源为预置数据，不是实际检索结果。

## 用户偏好 · 单元一：结构、校验与本机保存

本节保留首次单元的结构设计与验证记录；后续设置窗口、主要静态文案、回答语言和后端时间上下文已接入，当前能力与真实验收结果见文末“设置接入与重启后复验”。

**问题如何处理**：损坏 JSON、未知版本、超大内容、非法语言或时区均安全回退；存储被禁用或写入失败时返回失败结果，未来界面必须区分仅本页生效与已保存成功。测试覆盖字段白名单、附加敏感字段不落盘、存储访问异常、跨日展示及纽约夏令时。

**后面如何优化**：下一单元接入设置窗口和保存反馈，再逐批完成文案字典及后端每次请求的偏好快照。以后有账号体系再提供跨设备同步；当前不保存聊天正文，不实现多标签页自动同步，也不把本机保存当作服务端授权或并发一致性机制。
