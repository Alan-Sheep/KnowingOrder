# 联网问答体验上线指引（2026-10-26）

> 目标：开通侧边栏「公开体验 → 联网问答体验」入口（Tavily 联网搜索 + 模型整理，独立于企业问答）。
> 代码与产物**已全部构建完成**（jar 21:49 / dist 已带公开问答开关 / Nginx 限流已写入配置），
> 你只需按下面 4 步执行，约 10 分钟。

## 架构边界（重申）

- **企业问答**：只读企业知识库，命中→带引用回答；未命中→"知识库没有相关资料"，**不联网**；
- **联网问答体验**：独立入口、独立会话，Tavily 搜外网 → 模型整理 → 回答附来源链接，**不碰企业知识库**；
- 两条业务零交叉，仅共用中转站模型账号。

## 第 1 步：注册 Tavily 拿 API Key（约 5 分钟）

1. 打开 https://app.tavily.com 注册（邮箱即可，免费档 **1000 credits/月**，无需绑卡）；
2. 登录后进入 Dashboard，复制 `tvly-` 开头的 API Key；
3. 免费档每次 basic 搜索扣 1 credit，Nginx 已限流（每 IP 每分钟 6 次），正常演示用不完。

## 第 2 步：上传产物（在项目根目录 D:\Self_Project\Demo\AnsweringSystem 执行）

注意：这个 jar 同时包含今天下午的全部企业问答修复（跨空间/检索排序/instructions 等），
如果第 0.5 步（数据规模文档里的部署）你还没做，这一步会一并覆盖，不用重复部署。

## 第 3 步：配置服务器（ssh root@8.155.137.88 后执行）

### 3.1 加 Tavily Key

```bash
vim /etc/rag-qa/env
```

在文件末尾追加一行（key 换成第 1 步拿到的）：

```
TAVILY_API_KEY=tvly-你的key
```

### 3.2 更新 Nginx（新增 /api/chat 限流）

```bash
cp /tmp/nginx-rag-qa.conf /etc/nginx/conf.d/rag-qa.conf
nginx -t && systemctl reload nginx
```

限流规则：每 IP 每分钟 6 次、突发最多 4 次，超出返回 429（不消耗 Tavily 额度）。

### 3.3 重启应用

```bash
systemctl restart rag-qa
```

等约 20 秒再验证。

## 第 4 步：验证

### 命令行验证（应返回业务 JSON，而不是 404）

```bash
curl -s -X POST http://8.155.137.88:8090/api/chat -H "Content-Type: application/json" \
  -d '{"question":"什么是开源软件"}' --max-time 100 | head -c 400
```

预期：`{"code":0,...}` 且 answers 里的 sources 带来源 URL。
若提示 `TAVILY_API_KEY` 未配置，检查第 3.1 步是否生效（`systemctl restart` 了吗）。

### 页面验证

1. 浏览器 Ctrl+F5 打开 http://8.155.137.88:8090；
2. 侧边栏「公开体验 → 联网问答体验」应能进入问答页（不再是"未开启"说明页）；
3. 问一个公开问题（如「2026 年世界杯冠军是谁」），确认回答带来源链接；
4. 确认页面提示"不检索企业知识、请勿输入内部资料"正常显示。

## 常见问题

- **额度用完了**：Tavily 控制台可看用量；免费档每月 1 日重置，或升级付费（$0.008/credit）。
- **429 Too Many Requests**：Nginx 限流生效中，等 1 分钟；演示时可临时把 `nginx-rag-qa.conf` 里 `rate=6r/m` 调大。
- **回答超时**：后端总时限 90s（最多 3 个子问题 × Tavily 搜索 × 模型整理）；Nginx 已给 120s。持续超时检查服务器出网是否正常。
- **想关掉**：把 `/etc/rag-qa/env` 的 `TAVILY_API_KEY` 清空并重启即可（接口仍存在但报配置错误）；彻底下线则回滚 nginx 配置 + 重传不带开关的 dist。
